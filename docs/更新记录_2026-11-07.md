# Under the Sea 更新记录

**日期**: 2026-11-07
**版本**: v1.4

本次更新让游戏从单一家庭使用,变成可以开放给其他孩子。每位玩家有自己的存档,界面改为英文,并加强了数据安全和多设备同步。

> 本文档在公开仓库中,不包含邮箱、game ID、密钥或后端配置。

---

## 1. 游戏账号

| 功能 | 说明 |
|------|------|
| game ID 登录 | 打开网页先输入 game ID,输入框自动填入上次使用的 ID |
| 创建 game ID | 玩家自定义 game ID 并填写邮箱,创建成功后发送邮件 |
| 查重 | 不同玩家不能使用同一个 game ID,大小写视为相同 |
| 重发 game ID | 输入邮箱后重发;一个邮箱绑定多个 ID 时,全部写在同一封邮件里 |
| 邮箱未绑定 | 提示 `User not found` |
| 切换玩家 | 百宝箱内点 `Switch player`,先保存进度再回到登录页 |

**game ID 规则**: 6-32 位小写字母、数字、`-` 或 `_`。

**邮件发送限制**: 同一邮箱 60 秒 1 封、每天 5 封;同一 IP 每天 3 次(含邮箱未绑定的重发尝试);普通 Gmail 每天最多 100 个收件人。

---

## 2. 界面与内容

- 所有按钮、提示和物品名称改为英文;玩家自己输入的内容不翻译
- 旧存档中的中文物品名在载入时自动转换为英文
- 文案统一为 `Investable`、`Withdrawable`、`game ID`
- 乘法口诀 (Times Tables) 从 1-4 扩展到 1-9,每题 30 秒
- 适配手机横屏;iPad 和电脑布局不变,手机竖屏不做适配

---

## 3. 多设备同步

| 情况 | 现在的行为 |
|------|-----------|
| 存档变化 | 约 1.5 秒后自动上传 |
| 回到前台 | 上传未同步的进度,或自动载入其他设备的更新 |
| 过期页面上传 | 数据库拒绝写入,弹窗要求 Reload,不会覆盖新进度 |
| 上传失败 | 30 秒后重试,恢复联网时立即重试 |
| 切换到后台 | 有待上传的进度时立即上传 |

---

## 4. 股价

- 所有玩家共用一份股价,5 分钟内全局只向 Alpha Vantage 刷新一次
- 没有玩家使用时不会自动刷新
- 按顺序请求各标的,避免同时请求被 API 限制
- 没取到的标的保留上次价格
- 5 分钟内重复点击刷新时,提示下次更新时间

---

## 5. 安全

- 关闭网页对数据表的直接访问,不能再批量读取存档和邮箱
- 查询邮箱、创建存档只能在服务端执行
- 发信密钥和 API Key 只保存在服务端,不写入网页
- 移除公开的默认同步码
- 清理测试存档和公开过的旧存档副本

**已知限制**: game ID 相当于密码,知道 ID 的人可以进入对应存档;`User not found` 提示可以用来判断某个邮箱是否注册过,IP 次数限制只能减缓批量试探。
